GOING LIVE
1. Upload everything here to your IONOS web root, keeping /assets as a folder.
2. .htaccess is a HIDDEN file and most uploaders skip it. It must be there,
   or clean links like /mere-vatan will 404. On GitHub you have to use
   "Add file > Create new file" and type the name by hand.

ADDING A SONG — no help needed
1. Open add-song.html.
2. Fill the form, press "Build the files".
3. Paste the one-line block into songs-data.js after  window.SONGS = [
4. Download the song page it gives you and upload it.
The catalogue, filters, counts and title band update themselves.

COUNTS
